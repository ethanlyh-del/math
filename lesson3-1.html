配方法

本堂重點：將二次函數改寫成「一個平方加一個固定的數」的形式，即可直接讀出最高點或最低點的位置與高度。

上游思想：為什麼要學這個？

大約一千兩百年前，巴格達有一位數學家花拉子米，在當時的學術機構「智慧宮」做研究。那時還沒有 x，也沒有等號，題目全用文字寫，花拉子米用畫圖來解。

他遇到的題目，畫出來是一個正方形旁邊接著一個長方形，要找出正方形的邊長。這兩塊拼在一起不是正方形，看不出邊長。花拉子米的辦法是：把長方形切成兩半，分別貼在正方形的右邊和下面，這時只缺右下角一小塊。把那一角補上，就拼成一個完整的大正方形。完整的正方形，只要知道面積就能求出邊長；拼不成正方形的形狀就做不到。

這個「補成正方形」的做法，就是配方法。花拉子米寫這些方法的書，書名裡有一個字 al-jabr，後來演變成英文的 algebra，也就是代數。

到目前為止，找最大面積的方法是一個一個試。配方法用同樣的拼圖想法改寫式子，最高點或最低點的位置會直接寫在式子上，不必再試。

同一塊地，籬笆換成 37 公尺

籬笆 40 公尺、靠牆圍成長方形，最大面積為 200 平方公尺，此時寬 10 公尺、長 20 公尺。

籬笆 40：y = 40x − 2x²　→　最大面積 200
籬笆 37：y = 37x − 2x²　→　最大面積 ？
相同的圍法，籬笆改為 37 公尺，最大面積為多少？

一條係數為 1 的二次函數

37x − 2x² 和前面看過的式子有兩點不同：x² 前面是 −2，答案也不是整數。為了先把方法本身看清楚，先換一條 x² 前面是 1、數字整齊的式子學會方法，學會之後再回到 37 公尺。

以下為一條不對應任何情境的二次函數。係數是乘在 x² 或 x 前面的那個數，例如 3x² 的係數是 3、−6x 的係數是 −6；x² 前面沒寫數字時，係數就是 1。

y = x² + 6x + 5
y = x² + 6x + 5 由三項相加：x²、6x、5。x² 稱為二次項；排在中間、只含一個 x 的 6x 稱為中間項，6x 的 x 是一次方，所以也稱為一次項，課本多用這個名稱；不含 x 的 5 稱為常數項，它的值固定不變。
此函數的最小值為何？發生於 x 等於多少？

改寫的目標

y = x² + 6x + 5 的最小值無法直接讀出，因為含有 x 的項分成 x² 與 6x 兩處。若能把這兩項合併成一個平方，情況就不同。

□ × □ = 4　→　□ = 2 或 −2
□ × □ = 3　→　□ = √3 或 −√3
概念複習：√ 是什麼？為什麼會有兩個答案？
意思√a 唸作「根號 a」，代表自己乘自己會得到 a 的那個正數。√9 = 3，因為 3 × 3 = 9。
大部分的數開根號不是整數，例如 √3 ≈ 1.732，就直接寫成 √3。
兩個答案「□ × □ = 9」的 □ 有兩個：3 和 −3，因為 (−3) × (−3) = 9 也成立。√9 只代表正的 3，負的那一個寫成 −√9。
所以□² = 9　→　□ = 3 或 −3，常寫成 □ = ±3，± 讀作「正負」。
只要式子寫成 □²，□ 就能直接開根號求出來。
x² + 6x + 5 不是這種形式，x 分散在 x² 與 6x 兩處。
目標 把含有 x 的部分改寫成 □² 的形式。
此方法稱為配方法。「方」指正方形，「配」為湊合。做法是先找出一個完整的正方形，由於它會比原式多出一塊，再把多出的部分減掉。改寫後的式子因此是「一個完整的正方形，減去多出的部分」。

x² 與 6x 的圖形

要湊出 □² 的形式，用面積來看最清楚。x² 為一個邊長 x 的正方形；6x 為一條寬 6、長 x 的長條。把這兩塊拼成一個正方形，邊長就是要找的 □。常數項 5 不含 x，拼正方形時用不到，配方完成後再把它加回去。

概念複習：面積是什麼？
意思面積是一個圖形佔了多大的地方，看它可以鋪滿幾個 1 × 1 的小方格。
算法長 5、寬 3 的長方形，每排 5 格、共 3 排，總共 5 × 3 = 15 格。所以長方形面積 = 長 × 寬，正方形面積 = 邊長 × 邊長。
單位小方格的邊長是 1 公尺時，面積的單位是平方公尺。
中間項 6x
x² 與 6x，可以拼出一個缺了一角的正方形。

驗算：把 (x + 3)² 乘開

圖上得到的邊長是 x + 3。

概念複習：兩個括號怎麼相乘？
規則前面括號的每一項，都要和後面括號的每一項各乘一次。兩項乘兩項，總共乘四次：
(a + b)(c + d) = ac + ad + bc + bd
例子(x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6
合併同類項3x 和 2x 都是「幾個 x」，可以合併成 5x，這叫做合併同類項。x² 和 x 不是同一類，不能合併。
乘開的結果
(x + 3)(x + 3)
= x·x + x·3 + 3·x + 3·3
= x² + 3x + 3x + 9
= x² + 6x + 9
乘開後確實出現了 x² 與 6x，另外多了一個 9。

值得注意的是 3x 出現了兩次，合併才成為 6x。括號內放的那個數，乘開後會成為兩倍；反過來說，括號內要放的就是中間項係數的一半。而 9 為 3 × 3，正是圖上右下角那一塊。

為什麼要減掉 9

湊出來的完整正方形比原式大，大出來的部分要扣掉，兩邊才會相等。

(x + 3)² = x² + 6x + 9　完整正方形的面積
x² + 6x = (x + 3)² − 9　缺了右下角那一塊
(x + 3)² 是完整的正方形，面積為 x² + 6x + 9。x² + 6x 是這個正方形少了右下角 3 × 3 = 9 的那一塊。兩者相差 9，所以要把 9 減掉。
代入數值檢查
取 x = 4：
x² + 6x = 16 + 24 = 40
(x + 3)² − 9 = (4 + 3)² − 9 = 49 − 9 = 40
原式完整的正方形多出來的
x² + 6x(x + 3)²9
x² + 4x(x + 2)²4
x² − 8x(x − 4)²16
x² − 10x(x − 5)²25
每一列多出來的數，都是中間項係數的一半再平方。6 的一半是 3，3 的平方是 9；−8 的一半是 −4，−4 的平方是 16。
中間項為負時，取一半得到的也是負數。例如 −8 的一半是 −4，括號內因此寫成 x − 4；而 −4 的平方是 16，仍是正數。
概念複習：負數的平方是多少？
規則負數乘負數得到正數，所以負數的平方一定是正的。
例子(−4)² = (−4) × (−4) = 16
容易搞混−4² 和 (−4)² 不一樣。−4² 是先算 4² = 16，再加上負號，等於 −16。有括號才是整個 −4 去平方。

常數項 5 的處理

配方只處理 x² 與 6x 這兩項，常數項最後再合併。

y = x² + 6x + 5
= [ (x + 3)² − 9 ] + 5　前兩項改寫成 (x + 3)² − 9
= (x + 3)² − 4　−9 + 5 = −4
含有 x 的部分只剩 (x + 3)² 這一個平方，其餘都是固定的數。(x + 3)² 的最小值為 0，發生於 x = −3，此時 y = −4。
紫色的點是圖形的最低點 (−3, −4)。綠色的兩點是圖形與 x 軸相交的位置，x 分別為 −1 與 −5。橫向的黑線是 x 軸，縱向的黑線是 y 軸。

練習

每一題都是先找出完整的正方形，再減去多出來的部分，最後合併常數項。

y = x² + 4x + 7
解答
= (x + 2)² + 34 的一半是 2，2 的平方是 4。(x + 2)² 比 x² + 4x 多 4，需減 4；再加原本的 7：−4 + 7 = +3。
y = x² − 8x + 10
解答
= (x − 4)² − 6−8 的一半是 −4，−4 的平方是 16。(x − 4)² 比 x² − 8x 多 16，需減 16；再加原本的 10：−16 + 10 = −6。
y = x² + 6x − 2
解答
= (x + 3)² − 116 的一半是 3，3 的平方是 9。(x + 3)² 比 x² + 6x 多 9，需減 9；再加原本的 −2：−9 − 2 = −11。

兩種改寫方式

同一條 y = x² + 6x + 5，有兩種改寫方式，各自方便回答不同的問題。

概念複習：因式分解是什麼？
意思把一個式子改寫成幾個括號相乘，是「乘開」反過來的動作。
例子(x + 1)(x + 5) 乘開是 x² + 6x + 5。反過來，把 x² + 6x + 5 寫回 (x + 1)(x + 5)，就是因式分解。
怎麼找要找兩個數，相乘得到最後的 5，相加得到中間的 6：1 × 5 = 5，1 + 5 = 6。
因式分解
(x + 1)(x + 5)
兩個括號相乘等於 0，表示其中一個括號為 0。
由此可知 y = 0 時 x = −1 或 −5，也就是圖形與 x 軸相交的兩個位置。
配方法
(x + 3)² − 4
平方的最小值為 0，發生於 x = −3。
由此可知圖形最低的位置在 (−3, −4)。
兩者為同一條曲線、同一個函數，只是寫法不同。

以配方的結果 (x + 3)² − 4 求 y = 0 的解。

解答
(x + 3)² − 4 = 0
(x + 3)² = 4
x + 3 = ±2　　平方等於 4 的數有兩個：2 與 −2
x = −1 或 −5
與因式分解得到的答案相同。配方的結果同樣能求出圖形與 x 軸的交點。

最低點所在的 x = −3，正好位於 −1 與 −5 的正中間。離這個位置左右等距的兩點，高度相同，這裡的高度都是 0。
兩者的差別在能處理哪些式子。把 x² + 6x + ＿ 的常數項從 1 換到 9，只有 5、8、9 拆得成整數括號：x² + 6x + 5 = (x + 1)(x + 5)、x² + 6x + 8 = (x + 2)(x + 4)、x² + 6x + 9 = (x + 3)(x + 3)；其餘六個都拆不開。能夠因式分解時，求 x 的解確實比較快；配方法則對任何二次式都可以進行（x 的最高次方是 2 的式子，稱為二次式）。

例如 x² + 6x + 3 無法拆成兩個整數的括號相乘，但配方仍可進行，得到 (x + 3)² − 6。

籬笆 37 公尺的式子

y = x² + 6x + 5 是用來學方法的；要解決的仍然是開頭的 37x − 2x²。這條式子還有一個地方和前面的例子不同。

y = 37x − 2x²

前面所有的例子，x² 的係數都是 1。這一條是 −2。下式中的 p 代表任何一個數。

(x + p)² = x² + 2px + p²　x² 的係數永遠是 1
任何寫成 (x + p)² ＋ 固定的數的式子，展開後 x² 的係數必定是 1。而 37x − 2x² 的 x² 係數是 −2，因此不可能直接等於這種形式。
圖形上也看得出來：x² 是一塊邊長 x 的正方形。−2x² 是兩塊這樣的正方形，而且前面是減號，代表要從面積中扣掉這兩塊。拼正方形的做法，需要的是一塊正方形加上長條；兩塊、而且是扣掉的，就沒辦法直接拼成一個正方形。所以要先把 −2 提出來，讓括號裡剩下 x² 這一塊。
