頂點就寫在式子上

括號外的常數就是最大值或最小值

配方完成的式子，形式都是「係數 × 平方 ＋ 常數」。括號外的那個常數，就是這個函數的最大值或最小值——係數為負時是最大值，係數為正時是最小值。

y = −2(x − 10)² + 200　→　最大值 200

理由分成三步：

步驟結果
(x − 10)²任何實數（數線上所有的數，包括正數、負數、0、分數和小數）的平方都大於或等於 0，所以只能是 0 或正數
× (−2)0 或正數乘上負數，只能是 0 或負數
+ 200200 加上一個不會是正數的東西，結果只會等於 200 或比 200 小
概念複習：正負數相乘、相除的符號
規則同號得正，異號得負。
正 × 正 = 正　負 × 負 = 正　正 × 負 = 負　負 × 正 = 負
例子3 × (−2) = −6　(−3) × (−2) = 6
除法也一樣40 ÷ (−2) = −20　(−8) ÷ (−2) = 4
所以 y 最大就是 200，而且只發生在括號等於 0 的時候，也就是 x = 10。拉動下面的滑桿可以逐一確認。

係數為正時方向相反：平方乘上正數之後只會是 0 或正數，用常數加上它，結果只會等於該常數或比它大，所以那個常數是最小值。例如 x² + 6x + 5 配成 (x + 3)² − 4，(x + 3)² 最小為 0，因此最小值是 −4，發生於 x = −3。

三個名詞

拋物線上有三個位置需要固定的稱呼。

頂點拋物線轉彎的那一點。開口向下時是最高的位置，開口向上時是最低的位置。
對稱軸通過頂點的那條垂直線。曲線以它為界左右對稱，離它一樣遠的兩個位置，高度相同。
極值最大值與最小值合起來的稱呼，也就是頂點的 y 座標。開口向下的函數有最大值，開口向上的有最小值。
概念複習：座標是什麼？
意思座標用兩個數標出一個點的位置，寫成 (橫向的值, 縱向的值)。第一個數叫 x 座標，第二個數叫 y 座標。
例子(3, 14) 表示從原點往右 3、往上 14。(−3, −4) 表示往左 3、往下 4。
容易搞混順序不能對調。(3, 14) 和 (14, 3) 是兩個不同的點。

從式子直接讀出頂點

配方完成的式子，不必畫圖也不必代入數字，就能看出頂點在哪裡。把前面配過的三題排在一起，可以看出兩個規律。

配方結果ahk頂點
(x + 3)² − 41−3−4(−3, −4)
−2(x − 10)² + 200−210200(10, 200)
2(x + 3)² − 132−3−13(−3, −13)
兩個規律：
・頂點的 x 座標，是使括號等於 0 的那個數。(x + 3)² 要 x = −3 才等於 0，(x − 10)² 要 x = 10 才等於 0。
・頂點的 y 座標，就是括號外的常數。

把這兩件事寫成通式（用字母代替具體數字、每一題都成立的寫法）：
y = a(x − h)² + k　→　頂點 (h, k)
括號內寫成 x − h，所以 x = h 時括號為 0，此時 y = k，頂點就是 (h, k)。

要注意括號是減號。式子寫成 (x + 3)² 時，要看成 (x − (−3))²，對照之下 h = −3，頂點的 x 座標是 −3，不是 3。
a、h、k 是代號，代表任何數：a 是提出來的係數，h 是使括號等於 0 的那個數，k 是括號外的常數。對回前面的表：(x + 3)² − 4 的 a = 1、h = −3、k = −4。這種寫法稱為頂點式，因為頂點的座標直接寫在式子上。

a、h、k 各自管什麼

頂點式 y = a(x − h)² + k 裡有三個字母。h 與 k 已經知道是頂點的座標，a 則是提出來的那個係數。這三個字母各自控制圖形上的一件事，拉動滑桿就看得出來。

h 控制圖形的左右位置，k 控制上下位置，a 決定開口的方向與寬窄。不論 a 為何，頂點都固定在 (h, k)。

a 等於 0 時，a(x − h)² 這一項整個變成 0，式子只剩常數 k，圖形是一條水平線，不再是二次函數。

概念題

1. 為什麼配方之後，就能直接讀出最大值或最小值？
錯：配方後仍有平方，還是二次函數。
對：含有 x 的部分集中成一個平方之後，平方最小是 0 這件事是已知的，所以頂點與極值能直接讀出來。
錯：−2(x − 10)² + 200 的係數仍是 −2。
錯：不是規定；係數為正時，那個常數是最小值。
2. 為什麼 x² + 6x 配方時，括號裡要放 6 的一半？
對：括號內放的數乘開後會變成兩倍，所以要放中間項係數的一半。
錯：中間項是奇數時也取一半，例如 3 的一半是 3/2。
錯：多出來的是 3 × 3 = 9，不是 0。
錯：取一半是因為乘開時會變兩倍，跟好不好算無關。
3. 為什麼 x² + 6x 要寫成 (x + 3)² − 9，而不是 (x + 3)²？
錯：減 9 是為了讓兩邊相等，不是習慣。
錯：兩邊本來就是同一個式子，圖形沒有移動。
錯：方向反了。不是先加再還，而是 (x + 3)² 本身就比 x² + 6x 大 9。
對：(x + 3)² 是完整的正方形，x² + 6x 少了右下角 3 × 3 = 9 那一塊，所以要減 9。
4. 已經學過因式分解，為什麼還需要配方法？
錯：能拆的時候，因式分解求 y = 0 的解反而比較快。
錯：因式分解跟開口方向無關，例如 −x² + 4x = −x(x − 4) 一樣拆得開。
對：兩者回答的問題也不同：因式分解方便看出 y = 0 的解，配方法方便看出頂點與極值。x² + 6x + 3 就是拆不開但配得動的例子。
錯：能拆開時，令每個括號等於 0，就能得到與 x 軸相交的位置。

進階練習

1. 有人把 y = −2x² + 12x − 5 配方如下，錯在哪一步？為什麼？正確的結果是什麼？
y = −2(x² − 6x) − 5
　= −2[(x − 3)² − 9] − 5
　= −2(x − 3)² − 9 − 5
　= −2(x − 3)² − 14
錯在第三行。−2 要乘進中括號裡的兩項，只乘了 (x − 3)²，漏了 −9：−2 × (−9) = +18。
正確是 −2(x − 3)² + 18 − 5 = −2(x − 3)² + 13，頂點 (3, 13)。
2. 有人把 x² − 10x + 4 配成 (x − 5)² + 25 + 4 = (x − 5)² + 29。錯在哪裡？
(x − 5)² 乘開是 x² − 10x + 25，本身就比 x² − 10x 多 25，多出的部分要減掉，不是加上去。
正確是 (x − 5)² − 25 + 4 = (x − 5)² − 21。
3. 從地面把球垂直往上丟，高度 = 出手速度 × 時間 − 5 × 時間²（5 來自重力，是示意值，不計空氣阻力）。出手速度每秒 15 公尺時，先寫出式子，再用配方找出球最高到幾公尺、發生在第幾秒。
設時間為 t 秒，高度為 y 公尺：y = 15t − 5t²
= −5(t² − 3t)　提出 −5，15t 除以 −5 得 −3t
= −5[(t − 1.5)² − 2.25]　−3 的一半是 −1.5，−1.5 的平方是 2.25
= −5(t − 1.5)² + 11.25　−5 乘 −2.25 得 +11.25
第 1.5 秒時最高，離地 11.25 公尺。
思考題
4. 能不能寫出一條二次函數，配方後頂點在 (2, −1)？寫成 ax² + bx + c 的樣子。這樣的式子有幾條？
頂點式是 y = a(x − 2)² − 1，a 可以是任何不是 0 的數，所以有無限多條。
例如 a = 1：(x − 2)² − 1 = x² − 4x + 4 − 1 = x² − 4x + 3。
a 不同，開口的方向或寬窄就不同，但頂點都在 (2, −1)。
