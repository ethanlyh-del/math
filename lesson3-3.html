頂點就寫在式子上

括號外的常數就是極值

配方完成的式子，形式都是「係數 × 平方 ＋ 常數」。括號外的那個常數，就是這個函數的最大值或最小值——係數為負時是最大值，係數為正時是最小值。

y = −2(x − 10)² + 200　→　最大值 200

理由分成三步：

步驟結果
(x − 10)²任何實數的平方都大於或等於 0，所以只能是 0 或正數
× (−2)0 或正數乘上負數，只能是 0 或負數
+ 200200 加上一個不會是正數的東西，結果只會等於 200 或比 200 小
所以 y 最大就是 200，而且只發生在括號等於 0 的時候，也就是 x = 10。拉動下面的滑桿可以逐一確認。

係數為正時方向相反：平方乘上正數之後只會是 0 或正數，用常數加上它，結果只會等於該常數或比它大，所以那個常數是最小值。例如 x² + 6x + 5 配成 (x + 3)² − 4，(x + 3)² 最小為 0，因此最小值是 −4，發生於 x = −3。

三個名詞

拋物線上有三個位置需要固定的稱呼。

頂點拋物線轉彎的那一點。開口向下時是最高的位置，開口向上時是最低的位置。
對稱軸通過頂點的那條垂直線。曲線以它為界左右對稱，離它一樣遠的兩個位置，高度相同。
極值最大值與最小值合起來的稱呼，也就是頂點的 y 座標。開口向下的函數有最大值，開口向上的有最小值。

從式子直接讀出頂點

配方完成的式子，不必畫圖也不必代入數字，就能看出頂點在哪裡。把前面配過的三題排在一起，規律會自己浮出來。

配方結果ahk頂點
(x + 3)² − 41−3−4(−3, −4)
−2(x − 10)² + 200−210200(10, 200)
2(x + 3)² − 132−3−13(−3, −13)
兩個規律：
・頂點的 x 座標，是使括號等於 0 的那個數。(x + 3)² 要 x = −3 才等於 0，(x − 10)² 要 x = 10 才等於 0。
・頂點的 y 座標，就是括號外的常數。

把這兩件事寫成通式：
y = a(x − h)² + k　→　頂點 (h, k)
括號內寫成 x − h，所以 x = h 時括號為 0，此時 y = k，頂點就是 (h, k)。

要注意括號是減號。式子寫成 (x + 3)² 時，要看成 (x − (−3))²，對照之下 h = −3，頂點的 x 座標是 −3，不是 3。

a、h、k 各自管什麼

頂點式 y = a(x − h)² + k 裡有三個字母。h 與 k 已經知道是頂點的座標，a 則是提出來的那個係數。這三個字母各自控制圖形上的一件事，拉動滑桿就看得出來。

h 控制圖形的左右位置，k 控制上下位置，a 決定開口的方向與寬窄。不論 a 為何，頂點都固定在 (h, k)。

a 等於 0 時，a(x − h)² 這一項整個變成 0，式子只剩常數 k，圖形是一條水平線，不再是二次函數。

概念題

三題都在問這個方法本身，而不是問計算的結果。

1. 配方法的目的是什麼？
(A) 把二次函數變成一次函數，計算比較簡單。
(B) 把式子改寫成「一個平方加一個常數」，讓含有 x 的部分集中在同一處。
(C) 把式子裡所有的係數都變成 1。
(D) 求出圖形與 x 軸相交的位置。
含有 x 的部分分散在兩處時，看不出最大或最小值在哪裡。集中成一個平方之後，因為平方的最小值是 0 這件事是已知的，頂點與極值就能直接讀出來。
2. 同一條二次函數，配方前的式子與配方後的式子是什麼關係？
(A) 配方後的式子是原式的近似值，會有一點誤差。
(B) 兩者是不同的函數，畫出來的圖形也不同。
(C) 兩者是同一個函數，只是寫法不同，圖形完全重疊。
(D) 配方後的式子只在頂點附近才成立。
配方的每一步都保持等號成立：多出來多少就減掉多少，提出去的係數最後又乘回來。代任何一個 x 進去，兩條式子算出來的 y 都相同。
3. 已經學過因式分解，為什麼還需要配方法？
(A) 因為因式分解算起來比較慢。
(B) 因為因式分解只能用在開口向上的函數。
(C) 因為因式分解無法得到圖形與 x 軸相交的位置。
(D) 因為能夠拆成整數括號的式子很少，配方法則對任何二次式都可以進行。
兩者回答的問題也不同：因式分解方便看出 y = 0 的解，配方法方便看出頂點與極值。x² + 6x + 3 就是拆不開但配得動的例子。

延伸

一元二次方程式有一條求解的公式：x = ( −b ± √(b² − 4ac) ) ÷ 2a。這條公式很難背，也看不出從哪裡來。

但它並不是另外一套方法。把 ax² + bx + c 用今天的步驟配方一次，再令 y = 0 繼續解下去，出現的就是這條公式——會配方法的人，不需要背它。
