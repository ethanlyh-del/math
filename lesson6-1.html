對數函數

把指數函數反過來問的函數，叫做對數函數。
指數函數是給了次數算出數量，對數函數反過來，是給了數量算出次數。
這種反過來問的方式，加減乘除和根號都寫不出來，所以數學另外造了 log 這個記號。

上游思想：為什麼要學這個？

到目前為止，指數函數回答的是「走了幾步，變成多少」：細胞分裂 20 次，會有 1,048,576 個。但很多時候，想問的是反過來的：要分裂幾次才到一百萬個？存款要放幾年才會變成兩倍？這種問題用試的只能夾出一個範圍，而且用加減乘除和根號都寫不出答案。

這裡要練習一種新的眼光：為「幾次方」這個答案造一個新的記號，讓反過來的問題也能寫成式子。

有了這個記號有什麼用？第一，可以直接算出要幾次、要幾年。第二，可以處理大到算不動的數字：3 連乘 5000 次，寫出來有兩千多位，換成這個記號只剩下 5000。在沒有計算機的年代，天文學家就是靠它，大幅縮短了繁重的計算。

先學會這個記號怎麼讀、怎麼算，再看它的三條規則和圖形。接著會用它處理鋼琴的音高、存款的利息這些實際的問題。

兩種問法

一個細胞分裂一次變成兩個，分裂 x 次之後的數量是 2x 個。

問法已知要求怎麼算
分裂 20 次有多少個次數 20數量220 = 1,048,576
分裂 10 次有多少個次數 10數量210 = 1,024
要分裂幾次才到一百萬個數量 1,000,000次數？
前兩列是把次數代進 2x 算出數量，代進去就得到答案。
第三列反過來：數量是已知的，次數才是要求的東西。

可以用試的。219 = 524,288 還不到一百萬，220 = 1,048,576 已經超過，所以答案落在 19 和 20 之間。再往下就試不出來了。

先看一個做得到的例子

把問題反過來問，本身不是什麼特別的事。前面學過的二次函數就做得到。

正著問　邊長 x 的正方形，面積是多少？
　　　　y = x2　　邊長 5 → 面積 25

反著問　面積 y 的正方形，邊長是多少？
　　　　x = √y　　　面積 25 → 邊長 5
反函數 原本是給 x 求 y，反過來變成給 y 求 x。這樣得到的函數稱為反函數。
任何函數都可以反過來問。y = x2 的反函數就是開根號，寫成 x = √y。平方等於 y 的數有正負兩個，邊長不會是負的，所以這裡只取正的那一個。
y = x2 之所以能反過來寫，是因為把式子移項就做得到——兩邊開根號，x 就單獨留在一邊。
概念複習：移項是什麼？
原則等號兩邊同時做一樣的事，等號仍然成立。
加減x + 3 = 10，兩邊同時減 3，得 x = 7。看起來像是 +3 移到右邊變成 −3，所以說「移項要變號」。
乘除2x = 10，兩邊同時除以 2，得 x = 5。
開根號x² = 25，兩邊同時開根號，得 x = 5 或 −5。

指數函數反過來寫不出來

同樣的動作換到 y = 2x 上。

y = 2x　→　x = ？
x 卡在右上角那個位置。加減乘除、開根號，這些做法都動不了指數位置上的東西。
式子本身很簡單，卻沒有辦法把 x 單獨移到左邊。

這種情況下，數學的做法是造一個新的記號，專門用來表示這個問題的答案。
log x = log2 y

唸作「以 2 為底 y 的對數」。
它的意思是：2 的幾次方會等於 y？答案就是 x。
log 這三個字母來自英文 logarithm，中文譯為對數。
變數出現在真數位置的函數，稱為對數函數。
之後畫圖時，會照習慣把兩個字母對調，寫成 y = log2 x。
x = log2 y
底數
寫在 log 右下角的小字
就是 2x 裡的那個 2
真數
寫在旁邊的大字
就是 2x 算出來的結果
底數和 2x 的底數是同一個數，真數則是 2x 算出來的值。兩個記號描述的是同一件事，只是問的方向相反。

兩種寫法對照

同一件事可以用指數的寫法記，也可以用 log 的寫法記。

指數的寫法這一行在說什麼log 的寫法這一行在問什麼
23 = 82 連乘 3 次，得到 8log2 8 = 32 的幾次方會等於 8？　3 次
210 = 10242 連乘 10 次，得到 1024log2 1024 = 102 的幾次方會等於 1024？　10 次
34 = 813 連乘 4 次，得到 81log3 81 = 43 的幾次方會等於 81？　4 次
103 = 100010 連乘 3 次，得到 1000log10 1000 = 310 的幾次方會等於 1000？　3 次
52 = 25
log2 32 = 5
同一列的兩行，陳述的是同一件事實，但問的方向相反。

23 = 8　已知的是次數 3，要算的是結果。把 2 乘三次就得到 8。
log2 8 = 3　已知的是結果 8，要找的是次數。2 要乘幾次才會到 8？乘三次。

兩行都成立，而且從任何一行都可以推出另一行。差別在於已知的是哪一個、要求的是哪一個。
log2 16 是多少
問的是：2 的幾次方會等於 16？
2 × 2 × 2 × 2 = 16，乘了 4 次，所以 log2 16 = 4。
log10 100000 是多少
問的是：10 的幾次方會等於 100000？
100000 後面有 5 個 0，也就是 10 乘了 5 次，所以 log10 100000 = 5。
log2 1 是多少
問的是：2 的幾次方會等於 1？
任何不是 0 的數，0 次方都是 1，所以 log2 1 = 0。
換成別的底數也一樣：log3 1 = 0、log10 1 = 0。
log2 0.5 是多少
問的是：2 的幾次方會等於 0.5？
0.5 就是 1/2，而 2−1 = 1/2，所以 log2 0.5 = −1。
真數比 1 小的時候，log 算出來是負數。

回到一百萬個細胞

開頭那個算不出來的問題，現在寫得出來了。

要分裂幾次才會到一百萬個？

2x = 1,000,000
x = log2 1,000,000
寫出來了，但這只是把問題換一種寫法，還沒有算出答案。
先前試出來的結果是：答案落在 19 和 20 之間，因為 219 = 524,288、220 = 1,048,576。

那 log2 1,000,000 到底等於多少？
