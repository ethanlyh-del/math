畫出二次函數
的圖形

本堂重點：拿到一條二次函數，湊齊四件事就能把圖畫出來——開口朝哪、通過 y 軸的哪裡、頂點在哪裡、跟 x 軸交在哪裡。

上游思想：為什麼要學這個？

很多事情，要等做完了才知道結果。球丟出去，才知道它落在哪裡；價錢訂下去，賣完一整天，才知道有沒有賺。結果不好，球已經丟出去了，攤位費也已經付了，只能下次再改。

這兩件事有一個共同的樣子：球的高度先往上、再落下；價錢從低往高訂，賺的錢先變多、再變少。兩者都是先升到一個最高點，再降下來，畫出來都是一條拋物線。

有些事情，做下去就改不了。噴水池的池子挖得太小，水柱就會噴到池外；邊條買回來才發現圍不出想要的大小，材料就浪費了。這些事情，最好在動手之前就先知道結果。

把情境寫成二次函數，式子裡就已經藏著整條曲線的樣子。讀得出這條曲線，就能在動手之前先看到結果，再決定要不要做、要怎麼做；也能反過來問：想要不賠錢，價錢可以訂在哪個範圍？

要讀出一條曲線，需要知道四件事：開口朝哪、圖形通過 y 軸的哪裡、跟 x 軸交在哪裡、頂點在哪裡。

要畫圖，需要知道四件事

二次函數寫成這樣：

y = ax² + bx + c
a 是 x² 的係數，b 是 x 的係數，c 是常數項。
要把一條二次函數的圖畫出來，需要知道四件事：開口朝哪、圖形通過 y 軸的哪裡、跟 x 軸交在哪裡、頂點在哪裡。
這四件事裡，哪幾件光看 a、b、c 就知道，不必計算？
點開對答案
看係數就知道要算才知道
一、開口朝上還是朝下——看 a三、頂點在哪裡——配方後直接讀
二、圖形通過 y 軸的哪裡——看 c四、跟 x 軸交在哪裡——令 y = 0 解出來

a 決定開口朝哪邊

拖動滑桿改變 a，其他兩個數固定不動。

a 1
a 是正的，開口向上，像一個碗，頂點在最低的地方。
a 是負的，開口向下，像一座山，頂點在最高的地方。
a 離 0 越遠，開口越窄；越接近 0，開口越開。a 等於 0 時 x² 整項消失，剩下的是一次函數，畫出來是直線。
只要看 a 的正負，就知道這條曲線是碗還是山，不必畫圖也不必計算。

c 就是圖形通過 y 軸的高度

把 x = 0 代進去試試看。

y = a × 0² + b × 0 + c
y = c
概念複習：0 乘任何數是多少？
0² = 0 × 0 = 0
任何數乘以 0 都是 0，所以 a × 0 = 0、b × 0 = 0。
兩項都變成 0，式子就只剩下 c。
x 是 0 的時候，前面兩項都變成 0，只剩下 c。所以圖形一定會通過 (0, c) 這個點。
c 2
改變 c，整條曲線上下移動，紅點永遠停在 y 軸上，高度就是 c。開口的方向與寬窄都不受 c 影響。
在情境裡，c 常常有具體的意思：x = 0 代表「還沒開始」的那一刻。

讀三條真實的式子

李灝宇 2026 年球季在大聯盟打出的全壘打，每一支的擊球初速、仰角與飛行距離都有紀錄。以下是其中三支：

概念複習：英里和呎是什麼單位？
意思美國常用的長度單位。棒球紀錄的速度用「英里每小時」，距離用「呎」。
換算1 英里 ≈ 1.609 公里　1 呎 ≈ 0.3048 公尺
例子402 呎 ≈ 402 × 0.3048 ≈ 122 公尺；時速 105.8 英里 ≈ 105.8 × 1.609 ≈ 170 公里。

由擊球高度（約 1 公尺）、仰角與落點，可以配出每一支的式子。x 是水平距離，y 是高度，單位都是公尺。
紅人　　y = −0.0041x² + 0.49x + 1
小熊　　y = −0.0058x² + 0.68x + 1
皇家　　y = −0.0038x² + 0.51x + 1
真實的球會受空氣阻力影響，下降那一段比上升那一段陡，以上是不計空氣阻力的簡化模型。
三條式子的 a 都是負的、c 都是 1。這代表什麼？
點開對答案
a 都是負的，所以三條都是山型，開口向下——球飛到最高再落下來。
c 都是 1，所以三條都通過 (0, 1)。那是球棒打到球的那一刻，球離地 1 公尺。

三支疊在一起看

a 決定開口的寬窄，a 離 0 越遠，開口越窄。三支的 a 是紅人 −0.0041、小熊 −0.0058、皇家 −0.0038：小熊那支的 a 離 0 最遠，開口最窄，曲線最瘦；皇家那支的 a 離 0 最近，開口最寬。
b 決定起點有多陡，b 越大球出去的角度越斜。三支的 b 是紅人 0.49、小熊 0.68、皇家 0.51，正好是球剛飛出去時，每往前 1 公尺上升的高度。
飛得最遠的那一支，是不是打得最高的那一支？
點開對答案
對手仰角最高點高度飛行距離
紅人26°約 16 公尺122 公尺

不是。飛最遠的皇家那支，最高點約 18 公尺，比小熊那支的約 21 公尺低。
紅人和小熊這兩支，擊球初速幾乎一樣（105.8 與 105.9 英里），差別在仰角：26 度對 34 度。仰角比較低的紅人那支，反而多飛了 4 公尺。
紅人和皇家這兩支，仰角幾乎一樣（26 度與 27 度），擊球初速比較快的皇家那支（110 英里）多飛了約 13 公尺。
真實的飛行距離還受風和球的旋轉影響，所以不是每一支都這樣。
