畫出二次函數
的圖形

籬笆 37 公尺的結果

籬笆 37 公尺、靠牆圍成長方形的地，寬設為 x 公尺，長是 37 − 2x 公尺。

忘記怎麼把 x(37 − 2x) 乘開？點開看一次
括號外面的數，要跟括號裡的每一項各乘一次。這個規則叫做分配律：
a(b + c) = ab + ac
（這裡的 a、b、c 代表任何數，跟二次函數裡的 a、b、c 是不同的用法。）

套到這一題：括號外面是 x，括號裡是 37 和 −2x。
x × 37 = 37x
x × (−2x) = −2x²

兩個 x 相乘寫成 x²，就像 3 × 3 寫成 3²。
所以 x(37 − 2x) = 37x − 2x²
面積
y = x(37 − 2x) = −2x² + 37x

配方後
y = −2(x − 9.25)² + 171.125
括號裡的 x − 9.25 等於 0 時，y 最大。所以寬 9.25 公尺時面積最大，長是 37 − 2 × 9.25 = 18.5 公尺，面積 9.25 × 18.5 = 171.125 平方公尺。
9.25 的平方不必算。配方做到「取一半」時就已經知道寬是 9.25，面積直接用寬乘長算出來就好。

要畫圖，需要知道四件事

二次函數寫成這樣：

y = ax² + bx + c
a 是 x² 的係數，b 是 x 的係數，c 是常數項。
要把一條二次函數的圖畫出來，需要知道四件事：開口朝哪、圖形通過 y 軸的哪裡、跟 x 軸交在哪裡、頂點在哪裡。
這四件事裡，哪幾件光看 a、b、c 就知道，不必計算？

a 決定開口朝哪邊

拖動滑桿改變 a，其他兩個數固定不動。

a 1
a 是正的，開口向上，像一個碗，頂點在最低的地方。
a 是負的，開口向下，像一座山，頂點在最高的地方。
a 離 0 越遠，開口越窄；越接近 0，開口越開。a 等於 0 時 x² 整項消失，剩下的是一次函數，畫出來是直線。
只要看 a 的正負，就知道這條曲線是碗還是山，不必畫圖也不必計算。

c 就是圖形通過 y 軸的高度

把 x = 0 代進去試試看。

y = a × 0² + b × 0 + c
y = c
0² 是多少？點開看一次
0² = 0 × 0 = 0
任何數乘以 0 都是 0，所以 a × 0 = 0、b × 0 = 0。
兩項都變成 0，式子就只剩下 c。
x 是 0 的時候，前面兩項都變成 0，只剩下 c。所以圖形一定會通過 (0, c) 這個點。
c 2
改變 c，整條曲線上下移動，紅點永遠停在 y 軸上，高度就是 c。開口的方向與寬窄都不受 c 影響。
在情境裡，c 常常有具體的意思：x = 0 代表「還沒開始」的那一刻。

讀三條真實的式子

李灝宇本季在大聯盟打出的全壘打，每一支的擊球初速、仰角與飛行距離都有紀錄。以下是其中三支：

日期對手擊球初速仰角飛行距離
4 月 26 日紅人105.8 英里26°402 呎（約 122 公尺）
7 月 22 日小熊105.9 英里34°388 呎（約 118 公尺）
6 月 27 日太空人93.8 英里37°369 呎（約 112 公尺）
由擊球高度（約 1 公尺）、仰角與落點，可以配出每一支的式子。x 是水平距離，y 是高度，單位都是公尺。
紅人　　y = −0.0041x² + 0.49x + 1
小熊　　y = −0.0058x² + 0.68x + 1
太空人　y = −0.0068x² + 0.75x + 1
真實的球會受空氣阻力影響，下降那一段比上升那一段陡，以上是不計空氣阻力的簡化模型。
三條式子的 a 都是負的、c 都是 1。這代表什麼？
點開對答案
a 都是負的，所以三條都是山型，開口向下——球飛到最高再落下來。
c 都是 1，所以三條都通過 (0, 1)。那是球棒打到球的那一刻，球離地 1 公尺。

三支疊在一起看

a 決定開口的寬窄。三支的 a 是紅人 −0.0041、小熊 −0.0058、太空人 −0.0068，數字越往下走開口越窄——太空人那支的 a 是 −0.0068，開口最窄，曲線最瘦。
b 決定起點有多陡，b 越大球出去的角度越斜。三支的 b 是紅人 0.49、小熊 0.68、太空人 0.75，正好是三個仰角的正切值。
飛得最遠的那一支，是不是打得最高的那一支？
點開對答案
對手仰角最高點高度飛行距離
紅人26°約 16 公尺122 公尺
小熊34°約 21 公尺118 公尺
太空人37°約 22 公尺112 公尺
不是。飛最遠的那一支，最高點反而最低。
紅人那支和小熊那支的擊球初速幾乎一樣（105.8 與 105.9 英里），差別只在仰角：26 度對 34 度。角度比較低的那支多飛了 4 公尺。角度太大時，力氣花在把球往上送，往前的部分就少了。

還差兩件事

開口朝哪、通過 y 軸的哪裡，看 a 和 c 就知道了。

但頂點在哪裡、跟 x 軸交在哪裡，光看 a、b、c 看不出來。這兩件事要怎麼找？
