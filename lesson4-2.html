公園的噴水池

噴嘴裝在水面上，水柱斜斜噴出去，升到最高再落回水面。實際量過：落點距離噴嘴 8 公尺，最高的地方離水面 8 公尺。

水柱的形狀可以寫成一條二次函數。x 是離噴嘴的水平距離，y 是離水面的高度，單位都是公尺。
y = −0.5x² + 4x
a 是 −0.5、c 是 0。從這兩個數可以知道什麼？
點開對答案
a 是 −0.5，小於 0，所以是山型、開口向下——水柱升到最高再落下來。
c 是 0，圖形通過 (0, 0)。噴嘴就裝在水面上，所以水平距離 0 的地方，高度也是 0。

最高的地方在哪裡（頂點的位置）

水柱最高到哪裡，看原本的式子看不出來。要配方。

提出 −0.5
y = −0.5(x² − 8x)

8 的一半是 4，湊成平方會多出 16，把它減掉
y = −0.5[ (x − 4)² − 16 ]

把 −0.5 乘進中括號，兩項都要乘
y = −0.5(x − 4)² + 8
把 −0.5 乘進中括號時，−16 那一項怎麼算？點開看一次
中括號裡有兩項：(x − 4)² 和 −16。
−0.5 要跟每一項各乘一次。

−0.5 × (x − 4)² = −0.5(x − 4)²
−0.5 × (−16) = +8　負乘以負是正

所以中括號拆開之後是 −0.5(x − 4)² + 8。
很容易只乘第一項就往下走，第二項要記得乘到。
括號裡的 x − 4 等於 0 時 x = 4，代回去 y = 8。所以頂點在 (4, 8)——水柱飛出 4 公尺時最高，離水面 8 公尺。跟實際量到的一致。

式子最後面的那個數，意思不一樣

原本的式子
y = −0.5x² + 4x
後面沒有常數項，所以 c 是 0：圖形通過 (0, 0)，噴嘴在水面上。
配方後的式子
y = −0.5(x − 4)² + 8
8 是頂點的高度，也就是水柱最高 8 公尺。
c 是通過 y 軸的高度，配方後最後面那個數是頂點的高度。這一題一個是 0、一個是 8，差很多。

跟 x 軸交在哪裡

x 軸就是水面。跟 x 軸的交點，就是水柱碰到水面的位置。這一題有兩條路可以走。

第一條路：提出 x

這一條式子的兩項都含有 x，而且後面沒有常數項，所以可以把 x 提出來：
y = −0.5x² + 4x = x(−0.5x + 4)
兩個東西相乘要等於 0，只有一種可能：其中一個是 0。
x = 0
或　−0.5x + 4 = 0　→　x = 8
−0.5x + 4 = 0 怎麼解？點開看一次
把 4 移到右邊，移過去要變號：
−0.5x = −4
兩邊同除以 −0.5：
x = −4 ÷ (−0.5) = 8　負除以負是正
提出 x 很快，但只有在沒有常數項的時候行得通。式子後面只要多一個數字，這條路就走不通了。

第二條路：用配方後的式子

配方後的式子是 −0.5(x − 4)² + 8。令 y = 0，解出來：
−0.5(x − 4)² + 8 = 0

把 8 移到右邊
−0.5(x − 4)² = −8

兩邊同除以 −0.5
(x − 4)² = 16

平方等於 16 的數有兩個：4 和 −4
x − 4 = 4　或　x − 4 = −4
x = 8　或　x = 0
為什麼平方等於 16 會有兩個答案？點開看一次
4 × 4 = 16
(−4) × (−4) = 16　負負得正

所以平方等於 16 的數有 4 和 −4 兩個。
同樣地，平方等於 9 的數有 3 和 −3；平方等於 0 的數只有 0 一個。
兩條路算出來一樣：交點是 0 和 8——噴出去的位置，和落回水面的位置。跟實際量到的 8 公尺一致。
提出 x 只在沒有常數項時行得通，配方後的式子則是每一條都能用。
另外，0 和 8 的中間是 4，正好是頂點的位置。曲線左右對稱，最高點一定落在兩個交點的正中間。

四件事湊齊，把噴水池畫出來

前面找到的四件事排出來。

開口朝哪

a = −0.5，是負的，開口向下，是山型，頂點在最高的地方。

通過 y 軸的哪裡

c = 0，圖形通過 (0, 0)，噴嘴就在水面上。

頂點在哪裡

配方後是 −0.5(x − 4)² + 8，頂點在 (4, 8)。

跟 x 軸交在哪裡

拆成 x(−0.5x + 4)，交點是 0 和 8。

把頂點和兩個交點標上去，再照著開口向下的方向連成一條左右對稱的曲線，水柱的形狀就出來了。
畫的時候從頂點開始最穩：先點頂點，再點兩個交點，三個點就決定了這條曲線的高矮胖瘦。

換一條自己走一次

罰球。球出手的時候離地 1.75 公尺，飛到水平 5 公尺遠的地方，剛好通過 3 公尺高的籃框。

y = −0.25x² + 1.5x + 1.75
x 是球飛出去的水平距離，y 是球離地的高度，單位都是公尺。這條式子是從出手高度、籃框的位置與高度配出來的。
把四件事一件一件找出來，再把圖畫到下面的格子上。
點開對答案

開口朝哪

a = −0.25，是負的，開口向下，球升到最高再落下。

通過 y 軸的哪裡

c = 1.75，通過 (0, 1.75)。那是球出手時離地的高度。

頂點在哪裡

提出 −0.25 得 −0.25(x² − 6x)，6 的一半是 3，多出 9 減掉：−0.25[(x − 3)² − 9] + 1.75 = −0.25(x − 3)² + 4。頂點 (3, 4)，飛出 3 公尺時最高 4 公尺。

跟 x 軸交在哪裡

令 y = 0 解出 −1 和 7。

這一題的 c 不是 0，所以圖形不通過原點——球是從手上出去的，出手時已經在 1.75 公尺高。
交點 −1 是什麼意思？球會飛到水平距離 −1 公尺的地方嗎？
不會。x = −1 是在出手位置的後方，球那時候還在手上，根本還沒被丟出去。式子算得出這個答案，但現實中不存在——這是適用範圍的問題。
另一個交點 7 才有意義：如果球沒進籃、一路飛下去，會在水平 7 公尺的地方落地。
籃框在水平 5 公尺、高 3 公尺的位置。把 5 代進去算算看，會得到 3——球剛好通過籃框。

如果係數不整齊呢

噴水池和罰球這兩條式子，配方之後的數字都還算整齊。

但係數不整齊的時候，配方的過程裡會出現一堆分數。有沒有更快的辦法？
