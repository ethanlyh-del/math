指數是 0 和負數的時候

乘冪相除的時候要把指數相減，而相減的結果可能是 0，也可能是負數。可是指數原本記錄的是「連乘幾次」，乘 0 次和乘負 1 次都沒有辦法想像。
這兩種情況要等於多少，不是由誰規定的，而是由前面那三條規則逼出來的——只要不讓算出來的答案自相矛盾，答案就只有一種可能。

指數是 0

23 ÷ 23 這個算式有兩種算法。第一種完全不用管指數，直接把上下算出來再相除。第二種用規則三，把指數相減。兩種算的是同一個算式，所以答案一定要一樣。

第一種　直接算
分子和分母完全一樣。任何不是 0 的數除以自己都是 1。
23 ÷ 23　=　8 ÷ 8　=　1

第二種　用規則三
乘冪相除，指數相減。
23 ÷ 23　=　23−3　=　20
兩種算法算的是同一個算式，答案必須一樣。那 20 是多少？
結論 a0 = 1
任何不是 0 的數，0 次方都是 1。
第一種算法算出 1，第二種算法算出 20。同一個算式只會有一個答案，所以 20 只能是 1。
這不是有人規定 0 次方要等於 1，而是如果 20 等於別的數，那 23 ÷ 23 就會有兩個不同的答案，前面三條規則就沒辦法同時成立了。
20 = 1　　50 = 1　　1000 = 1　　0.50 = 1
直覺上很容易答成 0，但 0 會讓上面那兩種算法對不起來。
用另一個例子檢查一次：54 ÷ 54
直接算：625 ÷ 625 = 1。
用規則三：54−4 = 50。
兩邊對照，50 = 1。換成任何底數，結果都一樣。
00 是唯一的例外，0 的 0 次方沒有定義。

指數是負數

23 ÷ 24 同樣用兩種方式各算一次。寫成分數之後，分子有 3 個 2 相乘，分母有 4 個 2 相乘。分母比分子多一個。

第一種　上下消掉
分子的 3 個 2 全部消完，分母還剩一個 2。
23 ÷ 24　=　1 / 2

第二種　用規則三
23 ÷ 24　=　23−4　=　2−1
兩種算法的答案必須一樣。那 2−1 是多少？
結論 a−s = 1 / as
（a 不能是 0，因為分母不能是 0）
第一種算法算出 1/2，第二種算法算出 2−1，所以 2−1 只能是 1/2。
寫成一般的形式就是：指數前面帶負號的時候，把整個乘冪從分子搬到分母去，搬過去之後負號就去掉。
例如 2−3，把 23 搬到分母，變成 1 / 23，也就是 1/8。
負指數換成分數算出來
2−11 / 211/2
2−31 / 231/8
4−21 / 421/16
3−4
10−2
提示　1 / 23 是多少？
先算分母：23 = 2 × 2 × 2 = 8
所以 1 / 23 = 1/8 = 0.125

分母越大，整個分數越小。底數大於 1 的時候，指數是負數，算出來的值一定小於 1。

換一條路看同一件事

前面兩節是用規則推出答案。同樣的結果也可以從數字的規律看出來。
把 23、22、21 排成一排，它們的值分別是 8、4、2。往右每走一格要乘以 2，所以反過來往左每走一格就是除以 2。照這個規律繼續往左走，會走到什麼地方？

從 23 = 8 往左：8 ÷ 2 = 4，就是 22。4 ÷ 2 = 2，就是 21。
再往左一格是 2 ÷ 2 = 1，那個位置寫的是 20。
再往左一格是 1 ÷ 2 = 1/2，那個位置寫的是 2−1。
這條路走出來的答案是 20 = 1、2−1 = 1/2，和前面兩節用規則推出來的完全相同。兩條路從不同的地方出發卻走到同一個答案，這表示這兩個值不是隨便填的。

10−1 = 1/10 = 0.1，100 = 1，101 = 10。
指數越大，值越大。指數是負的時候，值會小於 1。
指數是 0 或負數的時候，前面那三條規則照樣可以用，不需要換一套算法。
上面第三題就是例子：25 × 2−3 一樣是指數相加，5 加上 −3 得到 2。
也就是說，0 次方和負指數不是三條規則之外的例外，而是把原本的規則用到更多情況上，所必然得到的結果。
