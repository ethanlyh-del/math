公式解

係數不整齊的時候

配方法每一題都做得動，但係數不整齊的時候，過程裡會出現一堆分數，比較花時間——例如 y = 2x² − 7x + 3，提出 2 之後括號裡就是 7/2、7/4、49/16 這些數字。

把配方的每一步用 a、b、c 走一次，整理到最後會得到一條可以直接用的算式。
x = −b ± √b² − 4ac 2a
概念複習：√ 是什麼？為什麼會有兩個答案？
意思√a 唸作「根號 a」，代表自己乘自己會得到 a 的那個正數。√9 = 3，因為 3 × 3 = 9。
大部分的數開根號不是整數，例如 √3 ≈ 1.732，就直接寫成 √3。
兩個答案「□ × □ = 9」的 □ 有兩個：3 和 −3，因為 (−3) × (−3) = 9 也成立。√9 只代表正的 3，負的那一個寫成 −√9。
所以□² = 9　→　□ = 3 或 −3，常寫成 □ = ±3，± 讀作「正負」。
這條算式叫做公式解。它不是另外一套方法，就是配方的過程整理出來的結果。
這條算式很長，很容易記錯。學會配方法的人不必背它——每一題都配得動，而且不會記錯。
概念複習：分數怎麼通分？
意思分母不一樣的分數要加減，先把分母變成一樣，這叫做通分。分子和分母同時乘同一個數，分數的值不變。
數字例子1/2 − 1/4 = 2/4 − 1/4 = 1/4　1/2 的分子分母都乘 2，變成 2/4。
含字母的例子c/a 的分子分母都乘 4a，變成 4ac/4a²，就能和 b²/4a² 相減。

整理的過程

步驟和前面配過的每一題完全相同，只是數字換成字母。

點開，看完整的過程
y = ax² + bx + c
y = a[ x² + ba x ] + c　把 a 提出來，只提含 x 的兩項
y = a[ (x + b2a)² − b²4a² ] + c　ba 的一半是 b2a，湊成平方會多出 b²4a²，把它減掉
y = a(x + b2a)² − a × b²4a² + c　把 a 乘進中括號
y = a(x + b2a)² − b²4a + c　分子分母的 a 約掉一個
配方到這裡就完成了。接下來令 y = 0，解出跟 x 軸的交點：
a(x + b2a)² − b²4a + c = 0
a(x + b2a)² = b²4a − c　把常數項移到右邊
(x + b2a)² = b²4a² − ca　兩邊同除以 a：左邊括號前面的 a 消失，括號裡不變；右邊兩項各自除以 a
(x + b2a)² = b² − 4ac4a²　右邊通分，分母都變成 4a²
x + b2a = ± √(b² − 4ac)2a　兩邊開根號
x = −b2a ± √(b² − 4ac)2a　把 b2a 移到右邊
兩項合成一個分數，就是前面那條公式解。

根號裡面的 b² − 4ac

兩個解長得一樣，差別只在根號前面是加還是減。所以跟 x 軸有幾個交點，完全取決於根號裡面的 b² − 4ac。

概念複習：≥ 是什麼意思？
意思≥ 讀作「大於或等於」。a ≥ 0 表示 a 是 0，或比 0 大。
四個符號> 大於　≥ 大於或等於　< 小於　≤ 小於或等於
例子遊樂設施規定身高 120 公分以上才能搭乘，寫成 身高 ≥ 120。剛好 120 公分也可以搭。
b² − 4ac > 0→兩個交點
b² − 4ac = 0→一個交點
b² − 4ac < 0→沒有交點
負數開不了根號，所以 b² − 4ac 是負的時候，這個方程式沒有答案——圖形碰不到 x 軸。
b² − 4ac 這個式子稱為判別式。「判別」指的是判斷交點的個數，不必真的把交點算出來。

配方也看得出來，而且是同一件事

用配方找交點，最後一步都會變成「一個平方等於某個數」。以罰球為例：y = −0.25x² + 1.5x + 1.75，配方後是 −0.25(x − 3)² + 4。

令 y = 0
−0.25(x − 3)² + 4 = 0

把 4 移到右邊
−0.25(x − 3)² = −4

兩邊同除以 −0.25
(x − 3)² = 16
16 是正的，所以平方等於它的數有兩個（4 和 −4），交點就是兩個。
換任何一條二次函數都一樣：配方之後令 y = 0，解到最後一定會走到這個樣子——
□² = △
□ 是含 x 的那個括號（這一題是 x − 3），△ 是右邊算出來的那個數（這一題是 16）。接下來只看 △ 是正是負：
△ > 0→兩個交點
△ = 0→一個交點
△ < 0→沒有交點
為什麼是這三種？因為一個數的平方不可能是負的：
△ 的情況平方等於它的數例子交點
正數有兩個，一正一負△ = 16　→　4 和 −4兩個
0只有一個，就是 0△ = 0　→　只有 0一個
負數一個都沒有△ = −16　→　找不到沒有
□² = △ 解出來有幾個 x，就代表圖形跟 x 軸交在幾個位置。△ 是負數時方程式沒有答案，圖形就碰不到 x 軸。
而 △ 的正負，跟 b² − 4ac 的正負一定一樣。這一題的 b² − 4ac 算出來是 4，跟 16 數字不同，但兩個都是正的，結論相同。
為什麼數字不同，正負卻一定一樣？
公式解解到最後那一步是：
(x + b ÷ (2a))² = (b² − 4ac) ÷ 4a²
等號右邊才是 △，而 b² − 4ac 只是它的分子。這一題的 4a² = 4 × (−0.25)² = 0.25，所以 4 ÷ 0.25 = 16——正好是配方解出來的那個數。
4a² 是一個平方，永遠是正的。除以一個正數只會改變數字的大小，不會改變正負。
所以判別式不必背。配方走到「□² = △」那一步，答案就在眼前了；判別式只是省掉配方那幾步，直接用 a、b、c 算出同一個結論。

練習

三題問的事情不一樣：第一題只判斷個數，第二題要畫圖，第三題要算出確切的答案。每一題都先自己動手，再點開對答案。

一、手作市集賣貼紙

一張貼紙賣 x 元時，大約賣出 40 − x 張。攤位費 300 元要先付掉，賺到的錢是收到的錢減掉攤位費。

有幾種定價會剛好打平（賺到的錢等於 0）？只要判斷個數，不必把定價算出來。
點開對答案
先自己列式再看
兩種定價會打平賺到的錢 y = x(40 − x) − 300 = −x² + 40x − 300。

a = −1、b = 40、c = −300
b² − 4ac = 1600 − 4 × (−1) × (−300) = 1600 − 1200 = 400，是正數，所以有兩個交點。

（算出來的話是 10 元和 30 元。中間那一段才有賺，兩端以外都賠錢。）

二、三分球

球出手時離地 2 公尺，飛出 4 公尺遠的地方到達最高點，離地 6 公尺。球的高度隨水平距離變化的式子是（示意值，實際依出手角度而異）：

y = −0.25x² + 2x + 2
把四件事找出來，再把球路畫到下面的格子上。
點開對答案
先自己做再看
頂點 (4, 6)，通過 (0, 2)，開口向下 開口　a = −0.25，是負的，開口向下。
通過 y 軸　c = 2，通過 (0, 2)，那是出手時球離地的高度。
頂點　提出 −0.25 得 −0.25(x² − 8x)（2x ÷ (−0.25) = −8x，除以 0.25 等於乘以 4），8 的一半是 4，多出 16 減掉：−0.25[(x − 4)² − 16] + 2 = −0.25(x − 4)² + 6。頂點 (4, 6)。
跟 x 軸交在哪裡　令 y = 0，解到 (x − 4)² = 24。24 開根號不是整數，算出來大約是 −0.9 和 8.9。

交點不是整數也沒關係：知道它大約落在 −0.9 和 8.9，就足夠把曲線畫出來了。畫圖時先點頂點 (4, 6) 和 (0, 2)，再往兩邊延伸到接近 x 軸的位置。

−0.9 那個交點在出手位置的後方，球那時候還沒被丟出去，現實中不存在。

三、舞台背板

場佈要用 24 公尺的邊條圍一個長方形背板，四邊都要圍。

要圍出 32 平方公尺，長和寬各是多少？這一題要把答案算出來。
點開對答案
先自己列式再看
4 公尺 × 8 公尺四邊都圍，一組長寬加起來是 24 ÷ 2 = 12。寬設為 x，長就是 12 − x，面積 x(12 − x)。

要等於 32：x(12 − x) = 32，整理成 −x² + 12x − 32 = 0。
配方：−(x² − 12x) − 32 = −[(x − 6)² − 36] − 32 = −(x − 6)² + 4
令 y = 0：(x − 6)² = 4，x − 6 = 2 或 −2，所以 x = 8 或 4。

兩個答案其實是同一塊背板：寬 4 配長 8，或寬 8 配長 4，只是長寬互換。

順帶一提，這條式子的頂點是 (6, 36)——24 公尺的邊條最多只能圍出 36 平方公尺，那時候是 6 × 6 的正方形。
如果要圍出 40 平方公尺呢？
點開對答案
−x² + 12x − 40 = 0，b² − 4ac = 144 − 160 = −16，是負數，沒有交點。
24 公尺的邊條最多只能圍出 36 平方公尺，40 超過上限，不管長寬怎麼配都做不到。

二次函數出現在哪裡

籬笆、全壘打、噴水池、貼紙，這些情境看起來各不相同，但會變成二次函數的原因只有幾種。

一、被拋出去的東西

做過的：全壘打、噴水池、罰球、三分球。
東西被拋出去之後，重力會一直把它往下拉，高度每次的變化量都不一樣。變化量本身在改變，就是二次函數的特徵。空氣阻力很小的時候，飛行的路線就很接近拋物線。
常用到的職業：運動科學研究人員和教練用它分析出手角度；遊戲程式設計師用它計算角色跳躍、物體掉落的路線。

二、周長固定，求面積

做過的：籬笆、舞台背板。
長和寬都跟同一個 x 有關。面積是長乘以寬，兩個含 x 的量相乘，就出現 x²。

三、價格乘以數量

做過的：演唱會定價、貼紙、園遊會飲料。
價格提高，賣出的數量就變少。營收是價格乘以數量，同樣是兩個含 x 的量相乘。這裡假設價格每漲 1 元，賣出的數量就少固定的量；真實的市場不一定剛好如此，這是一種簡化的模型。
常用到的職業：經營、行銷、經濟分析，用來估計營收最高的定價。

四、拋物面

把拋物線繞著對稱軸轉一圈，會得到一個碗狀的曲面，稱為拋物面。從正前方平行射進來的光或訊號，碰到拋物面反射之後，都會集中到同一個點，這個點稱為焦點。
衛星天線把訊號集中到焦點上的接收器；有一種太陽能發電，把鏡面做成剖面是拋物線的長槽，陽光反射後集中到槽中間的吸熱管。這兩種的剖面都是開口向上的拋物線。
常用到的職業：通訊工程師、能源工程師。
看到兩個會一起變的量相乘，或是重力拉著東西走，就可以猜猜看背後是不是二次函數。

2.

噴水池的式子是 y = −0.5x² + 4x。寫成 y = ax² + bx + c 的樣子時，c 是不含 x 的那一項，稱為常數項。這條式子沒有常數項，所以 c 是 0。

配方後寫成 y = −0.5(x − 4)² + 8，最後面的數是 8。

為什麼 c 是 0，配方後最後面的數卻是 8？
(A) 因為配方的時候算錯了。
(B) 因為 c 只在開口向上時才有意義。
(C) 因為兩個數指的是曲線上不同的點：c 是 x = 0 時的高度，8 是頂點（x = 4）的高度。
(D) 因為配方會讓圖形往上移 8。
